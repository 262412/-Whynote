# M5-5 作者开发证据

运行正文、源文件、投影库、缓存及完整 journal 留在获准的项目 `var/research/m55/`。
本目录仅保存来源身份、计数、延迟/资源指标、边界核验和明确的合成复现脚本，不包含真实问答或反馈。
独立 QA 与责任人签署另行完成；本目录不能作为独立原因标签或质量通过证明。

`developer-validation.json` 为自动汇总，保留各候选的身份和历史失败。
`scripts/*.py.txt` 是本机实际执行脚本的原文归档，不是自动执行的测试。
以 UTF-8/LF 规范化后核对 `scripts/manifest.json` 的摘要；Git 在 Windows 检出时可能转换 CRLF。
复跑时复制为 `.py`，用记录的专用 Laya Python `-I -B -X utf8` 执行，先把输出路径改为新的受控子目录，不能复用或覆盖历史目录。
这些脚本使用固定本机基础 Python 和模型位置；其他机器必须显式配置对应位置并重新记录指纹。

常规真实批次复现优先使用 README 的 `whynote.explore` 入口。
耐久脚本只用三种明确合成输入，预热后计时 1800 秒；每次调用和资源采样均落本机 journal。
边界脚本只使用合成载荷和指定本机 TCP/UDP 探针，不把该有限检查解释为穷尽的出站安全证明。
