## 本次测试契约

- 仅回环地址、新建独立宿主数据目录和单一普通测试用户；不读取旧聊天。DeepSeek 沿用已签 v1、100 CNY 累计预算、60 秒、单并发、无自动重试。凭据由服务端私有文件读取，浏览器不接触 API Key。
- 点踩和原因菜单沿用主干。额外按钮仅在服务端 `WHYNOTE_LOCAL_CHAIN=1` 时可用；先核对认证、所有权、当前保存回执和有效点踩，再读取该条问题及回答，送到固定本机 `127.0.0.1:8766`。不附带历史、已选原因、用户反馈、邮箱或 Key。
- 推理完成后重新核对开关、对象版本和同一有效点踩；删除、编辑、重生成、撤回或停用时丢弃结果。Laya 失败不修改已有动作。请求不重试、不重定向；沿用本机模型输入上限。
- 建议以独立提示展示“模型推测，未确认、未经校准”。不默认选中、不写 confirmed/selected、不改变动作和 Outbox。用户之后打开常规菜单明确选因，仍按既有 manual-v1 记录。此测试不记录建议曝光或因果效果，不能用于正式研究统计。
- 默认研究记录、自动附加、训练导出关闭。重复手动请求可能重新推理，但不追加反馈事件；Laya 服务已有单并发保护。
- 云正文只在本次宿主保留，沿用试用结束后七天内清除；日志/事件不复制正文和 Key。关闭启动服务可停用入口；保留数据库预算，重启不重置累计费用。

## 使用

启动器、登录信息和独立数据库位于主项目 `var/local-chain/`，不进入 Git。页面 `http://127.0.0.1:8128`，Laya 使用已安装的 `http://127.0.0.1:8766`。先登录并选择“知因 DeepSeek 本机联调”，发送非敏感文本；点踩后可关闭菜单，再点击“获取 Laya 原因建议”，按建议或自己的判断通过常规菜单选择/更正，最后测试撤回。

较长答案可能超过 Laya 700 token 上限，届时提示失败；不静默截断。建议先要求 DeepSeek 用一两句话回答。Laya 输出质量尚未达标，本轮只验证连通和行为，不能把建议当正确标签。

启动：主目录 `var/local-chain/start.cmd`（依赖保留的隔离工作树、固定宿主构建和原生运行环境）。停止 Open WebUI：`var/local-chain/stop.cmd`；Laya 独立停止使用 `var/laya/stop.cmd`。重启保留同一数据库和预算，不能重新 provision。登录账号与随机密码见 `var/local-chain/login.txt`；勿提交该文件。
