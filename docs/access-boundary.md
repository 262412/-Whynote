# 对象归属复核契约

状态：TD-01/TD-04 的服务端权限边界切片；对应 PRD FR-01、FR-10、FR-11、FR-13。飞书核对版本：PRD 修订 66、技术文档修订 7（2026-09-25）。现有平台的身份、对象权限接口及批准的数据流仍待提供，本切片不代表真实平台鉴权已经接入。

## 请求边界

- 宿主平台在 `create_app` 注入已经验证的 `authenticate` 与 `authorize_target`；默认配置拒绝业务请求。客户端提供的目标 ID 或身份字符串不能直接当权限凭据。
- 创建动作前校验目标对象的类型、ID、不可变版本与当前用户的写权限。
- 对已有动作的查询、撤销和归因提交，先按租户及创建者查出持久化的目标引用，再用宿主提供的对象权限检查当前访问资格。权限已撤销或目标不可见时返回 404，不读取事件投影、不追加事件、不消费幂等键；恢复权限后可重试。
- `EventStore.record_display` 仍是可信宿主内部接口；宿主在调用前必须核验当前对象权限，公共客户端不能直接写展示确认。

对象引用只含不透明标识和版本，不含问题或回答原文。权限回调必须按所存 `object_version` 判定，并由宿主定义撤权与对象删除语义。本仓库目前没有宿主平台适配器；未接入前不处理生产反馈或读取生产上下文。

## 兼容、验证与回滚

不改变事件、API 请求字段或 SQLite schema；已有事件与幂等记录继续重放。验证范围包括撤权后查询、撤销、归因和幂等重试均被拒绝，授权恢复后可继续操作，跨用户动作仍不可见。回滚到旧版本会重新允许创建后已失去目标访问资格的用户读取或修改自己的旧反馈，不可作为生产回滚方案。
