## 3. 单人盲审与来源规则

1. 探索30例可查看问题、回答与原评价以理解类别缺口，但原评价/用户动机/答案缺陷分层记录，不冒充本工具用户确认。
2. 验证60例在理由包冻结后抽取；本人只看预测允许的上下文，先隐藏原评价、事后反馈、模型输出和置信度，写defect/no_defect/unjudgeable、可支持的完整reason_ids、legacy_reason_codes、参考任务/领域及依据。库外缺陷保留defect＋空理由集合，不能改为无缺陷。
3. 固定抽20例隔48小时重标，保留两份结果及差异。若“缺陷判定或理由集合不一致”的例数>4/20，判为标注协议尚不稳定，先修订并重新封存验证版本；不看预测后重标来提高分数。<=4/20也不证明独立性，只允许继续预试验。全部60例在模型运行前封存最终标签/hash。
4. 已知本人曾查看过目标的模型预测或先前评价时记录exposure_flag；这类样本转探索并在运行前重新抽取，不能悄悄称盲审。运行开始后不替换样本，缺失/排除保留清单。
5. 新标签来源为self_reviewed_blind，另存标注/重标时间与文件hash；不得伪造两个reviewer_refs或independent_adjudicated。现有replay_metrics只接受独立标签，新轨需独立schema与报告scope，不放宽旧schema来混入自评。
6. 原评价和用户自述是分离材料；任何反馈/gold/未来轮次不得进入预测。用户确认事件不从离线标签创建。模型之后的引文支持性审查单列，不能反改缺陷标签。

## 4. 指标、分母与预试验退出门槛

记N=60；J为defect或no_defect例数，D为defect例数；S为J中实际给出具体建议的例数。全部方案逐例报告，**退出判断只针对预先指定的C**。任何最小分母不足都记INCONCLUSIVE，不补样到过线、不当PASS；改善后另立固定新批次。

| 指标 | 本轮冻结口径 | C的工作门槛 |
| --- | --- | --- |
| 标签与样本完整 | N例均有封存标签，分组无泄漏；J、D独立列出 | J>=40，D>=30，无缺陷J-D>=10；标签完整60/60；盲重标分歧<=4/20 |
| 理由库覆盖 | 库至少覆盖一个真实问题的例数/D，库外问题仍在D内 | >=80%，D>=30 |
| 路由遗漏 | 有库覆盖且路由成功的缺陷例中，最终routed_ids无正确理由的比例；初始路由与回退后分别报 | 回退后<=10%，条件分母>=20；route不可用另报，不稀释分母；材料不可用另列 |
| 端到端命中 | 至少命中一个已标问题的例数/D，运行失败、拒识、缺材料和超长均不能从D删除 | >=50%，D>=30；不声称覆盖一条回答的所有缺陷 |
| 错误具体建议 | J中给出任何不受完整标签支持的具体理由的例数/S（含无缺陷却提出问题） | <=5%，S>=20；即S=20时最多1例。区间照报，不称已证明总体误导<=5% |
| 可判却拒识 | 有可用正确候选且运行成功的缺陷例中unknown/no_match比例 | <=30%，条件分母>=20；与选择错误分列，不再统称judgment_error |
| 无法判断仍建议 | unjudgeable中提出具体理由的比例与逐例记录 | 只要出现1例就HOLD并人工审阅，不能自动按安全通过；分母0为NA，不宣称验证过 |
| 输入适用范围 | 满足已冻结全部字节/token/材料前置的样本/N | >=70%；未满足全部保留并说明，不能静默截断 |
| 技术失败 | 已满足输入预算的样本中，异常/超时/模型加载失败的比例；合法unknown/no_match不是技术失败 | <=5%，有效预算分母>=30；未捕获异常或未记录失败立即停止 |
| 等待成本 | 满足预算的全部尝试的总耗时（含进程启动、路由/回退、错误/超时），nearest-rank p95 | <=15秒，分母>=30；60秒硬超时。UI主动操作时间另在4b测 |
| 引用/安全边界 | 引用存在与支持该指控分开；当前live无定位时只显示类别 | 无引用NA，不补零；伪造行号/声称已执行代码、越权/泄露/未准许出站/非法重复写入任一例立即停止 |

这些点估计阈值选择的产品理由：先保证多数缺陷能表达、至少一半缺陷可给出有用候选；具体错误建议从严限制，避免把用户带偏；拒识与运行失败不得靠删分母制造高准确；超过15秒会妨碍轻量点踩体验。它们只决定是否值得本人试用，不能证明相比常规菜单已省时。

A/C改变理由库和提问形式，只比较整方案；不把差异解释为纯路由收益。B/C做原因诊断。本轮不做赢家选择或多重假设显著性声明。若C不达标，保留常规菜单并查看错误归因；不得赛后自动选A/B宣称本轮通过。

5. 正式运行一次固定60例×3方案，无自动重试。计划性失败保留并继续；泄漏/越权/非法写入、标签泄漏或哈希漂移立即停止。一次基础设施中断只可在预测结果未对调参者揭盲且模型/协议/标签未改时续跑缺失项，原失败和attempt记录保留，原主分析不覆盖；否则新协议/新批次。
6. 所有门槛通过只写PASS_SELF_REVIEW_PILOT；任何已测硬门槛失败写FAIL，有人工风险待审写HOLD，信息/分母不足写INCONCLUSIVE。不得把范围通过写成完整FR或独立验收。
