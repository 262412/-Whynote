## 产品路线与自动入口边界

来源/使用范围登记 → 三源下载 → 统一输入 → 本机Laya批量运行 → 诊断报告 → 正式批次准入 → 探索审阅 → 理由包冻结 → 新留出集 → 盲标复标 → 冻结运行 → 判断质量。

从自动入口移除人工标签、48小时复标、固定30/60/180与中文任务配额、人工签署和正式冻结门槛；旧evaluate协议与证据保留在后置阶段。默认跑候选C，A/B可选；不改为模型排名项目。无标签只报告运行与诊断，正确率等为NA，不生成质量PASS。数据使用范围、目标关联、反馈隔离、token预算与运行保护保留为自动检查。
