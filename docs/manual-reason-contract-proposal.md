## 1. 显式操作

点踩受理即完成反馈，选因可选。所有原因操作绑定认证主体、对象版本、event_id 和当前有效 display_id；旧菜单、外人、已撤销、到期或换版拒绝且零追加。同一提交键重试返回原结果，不重复计数。

| 用户操作 / 中文文案 | 新事件或沿用事件 | 当前原因 / 来源 | 后续与统计 |
| --- | --- | --- | --- |
| 仅点踩 | negative_feedback_action_recorded | 空 / none | 不等于拒填或确认 |
| 选择原因 | reason_selected | 所选码 / user_manual | 单选；明确提交才算填写 |
| 更正原因 | reason_edited | 新码 / user_edited | 旧事件保留，不再计一次点踩 |
| 都不是 | reason_none_matched（新增） | 空 / none | 明确表示列表不适用；不是 unknown 类别，不算有原因填写；编辑时也可明确清除当前原因，旧记录仍保留 |
| 暂时跳过 | reason_skipped | 初次为空；已选原因保持不变 | 与拒填分别计；以后可重开选择，不把“稍后”解释为永久拒绝 |
| 不愿说明 | reason_declined | 初次为空；已选原因保持不变 | 明确拒填，可在后续主动重开后选择；不据此推断真实动机 |
| 关闭 / 取消 | reason_menu_closed（新增） | 原因及来源保持不变 | 只表示关闭；不暗转为跳过、拒填或撤销 |
| 撤销点踩 | action_retracted | 按既有契约清空当前原因 | 保留历史，单列动作撤销 |

来源使用两层：`attribution_source` 只描述实际原因；新增响应事件的 `response_source=user_explicit` 只证明用户操作，不把无原因冒充用户原因。系统超时或断线没有用户操作事件；0 点击永不视为 confirmed。模型推测、用户提交和 gold 不互转。

常规菜单固定顺序：事实有误、未按指令、回答不完整、答非所问、表达方式不合适、信息过时、不必要的拒绝、其他或无法归类。沿用 `candidate-v1` 的 8 个原因码，其中 `other_or_unknown` 是用户明确选择的类别，不用于填补空原因；本轮不拆改历史 taxonomy。菜单版本为 `manual-menu-v1`。八类之后单独放置“都不是 / 暂时跳过 / 不愿说明 / 关闭”，不将这些操作作为原因码。

## 2. 动作与展示去重

同一 tenant、actor、target_ref、target_version 的当前有效点踩，跨会话复用同一 event_id；session_id 不划分新意图。再次点击独立入口按既有明确操作参数决定重开菜单或撤销，不能把跨会话重复回调当作新意图。撤销后再次主动点踩创建新 event_id；客户端请求幂等键仍防止旧请求重复创建。

展示按 display_id 去重；一个 event_id 可有多次展示，但只有最后签发菜单有效。保留现有 60 秒票据安全期限，与下面测量观察窗分开。渲染回执只证明客户端报告渲染，不证明用户实际看见。

## 3. 未响应及迟到（已确认）

- 观察窗为 **24 小时**，从服务端动作 accepted_at 开始，用服务端 UTC 时间计算；此数值只用于虚构功能验证，不是研究实验阈值。
- 未响应采用**派生统计，不新增定时事件**：到达 accepted_at+24h 且窗内无选择、更正、都不是、跳过或拒填，记 `unresponded`；只有关闭仍可进入未响应。无展示回执为 `display_unknown` 单列，不与已报告展示的未响应混算；断线/票据到期无法证实原因时不猜测意图。
- 已撤销动作单列 `retracted`，不产生未响应。未满窗口记 `pending`。首次明确响应和窗末结果分别输出；重复开关菜单不增加动作数。
- 窗后用户可通过新有效菜单提交，按正常规则追加，标 `late_response=true`；24h 内视图保留原结果，当前状态可更新，不追改历史事件。报告必须包含 as_of、window_seconds、metric_version。

## 4. 指标及兼容

- 动作完整性：唯一成功意图、event_id、动作事件、Outbox 一一对账；请求重试、失败和撤销另报。
- 填写率：固定资格 cohort 中窗内明确提交原因的唯一 event_id / 该 cohort 所有成功点踩。撤销仍在原成功动作分母中且另报，不能事后通过剔除撤销提高填写率。本轮 cohort 仅虚构测试资格，不用推断门控成功冒充菜单资格。
- 响应分类：都不是、跳过、拒填分别计；关闭次数与唯一动作数分报。明确选择 `other_or_unknown` 算用户填写，空值不算。
- 耗时：同一客户端以单调时钟测挂载→明确提交主动耗时，失焦暂停；服务端受理→提交总时长单列。客户端时钟缺失、跨会话及不可解释值输出空和缺失原因，不从墙钟拼造主动时长。中位数/p90 只用有效值并报告样本数。
- 事件只追加，增加事件类型及投影版本，不重命名旧事件；`inference_status=denied` 保留为门控执行状态，产品展示可映射“未推断”，不回写 not_inferred 改历史。
- 旧客户端与旧事件维持原语义；旧 `reason_unresponded` 原样重放，新的测量报告不把它当作明确用户响应。新增字段缺失时标 legacy/unknown，不伪造菜单版本、观察窗或耗时。旧投影不认识新事件，禁止无说明回滚到旧投影继续处理新日志。
