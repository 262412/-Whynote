# M5-2b 合成模板交互契约

需求：FR-04/06/09/10/11/13/14/15；TD-01/02/04/07/09/10/11；D-13/17/18。
输入为 PRD350 / 技术350，基线 main `3f4c9e8`。2026-09-28 用户明确本轮先完成合成验证，真实试用参数另行确认。

## 范围与数据流

`suggestion_template_enabled` 默认 false，必须同时开启 mock、research_enabled、suggestion_research_enabled。服务端 `suggestion_fixture` 指定任务、1–3 个合成预测及引用坐标；浏览器不能指定这些值。不调用真实模型，不读取历史、附件或自由文本反馈。现有真实 DeepSeek/Laya 联调不改变。

同一个 local-chain 点踩按钮先提交动作与 Outbox，再运行建议路径。m52 接受 `openwebui-local-chain` 的 manual-v1 动作；旧 `openwebui-s1` 继续有效。门控和研究登记通过后才读取已校验的直接父问题与当前回答。显示前、每次回调及事务内重新核对权限、对象版本、研究开关与当前动作。合成预测失败/拒识、无法使用客户端或“不是/都不是”时保留动作并提供原 manual-v1 菜单。

## 原文和固定模板

引用选择器限定 source=request/answer，start/end 为 Python Unicode 字符偏移，source_sha256 绑定完整原文；最多每个候选两段、每段1200字符。有效引用必须精确匹配当前对象版本与完整源摘要；只有直接问题内完整闭合的 fenced code 才提供 original_code 证据。没有可靠引用时只显示类别，不能编造定位或错误。模板来自冻结小理由包，引用原文使用 DOM textContent 显示。

引用只证明位置匹配，不证明该段支持模型判断。UI明确标记“合成模型建议，未确认；原文仅供核对，未运行代码”。事件 binding 的可选 presentation 仅包含 UI 版本及 reason_id/source/start/end/source_sha256/quote_sha256/object_version；正文只存在于宿主原记录和短期展示内存，不进入事件、Outbox、普通日志或研究报告。

## 展示和响应

新增宿主事件 `whynote:suggestion-render`、`whynote:suggestion-response`、`whynote:suggestion-dismiss`。客户端创建对话框、以 textContent 插入内容并经过绘制帧后，返回完整 binding；服务端接到实际回执才追加 m52_render_reported。初始按钮禁用，下一请求核对 display_id 后开放响应。0点击不产生确认；确认、不是、都不是、跳过、拒填、关闭分别记录。是/不是必须绑定一个已展示 reason_id；确认后可在原候选间显式更正。都不是拒绝整组建议但不清空既有原因；常规菜单保留其原有“都不是清空”语义并单独说明。

同一生成总有效期60秒。客户端时效仅辅助，服务端在回调到达时及事务内核验；迟到、撤销、换版、研究停用均拒绝。重试生成也必须仍然当前且有效。动作撤销清空当前确认的 response_id，保留 last_response_id 历史。未返回渲染回执保持 render_unknown，不把派发请求当成渲染。

Q-27澄清（输入PRD371/技术370）：渲染与响应均使用服务端回调到达时间判断是否在生成后的 `[0,60)` 秒内；在宿主异步复查及SQLite事务等待之前捕获并传递该时间。事务内仍以最新状态复核主体、动作、研究开关、协议、对象版本和当前建议。按时到达但复查/排队跨过截止点的回执可写入；此后新到达的响应仍按原截止点拒绝。`render` 新增可选关键字参数 `server_received_at`，未传时在进入事务前捕获；仅服务端内部调用可传入，客户端不能提交该字段。事件结构、既有历史与60秒期限不变。

响应可附 client_reported active_ms/elapsed_ms；数值必须有限、非负、active≤elapsed，并与服务端观察时长相容。报告分开给出每次响应耗时和缺失，不将缺失填零。补写需求、必要补充、误导裁决和真实效用本轮不采集，不由按钮计数推断。
