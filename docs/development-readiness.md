数值目标、最小有意义改善、样本量、实验单位、观察窗、分配与停止规则须实验前签署，不能按结果补定义；按版本和来源切分。

| 指标 | 最小可测口径 |
| --- | --- |
| 动作完整性 | 去重有效意图→受理→持久化对账；核对成功回执是否对应唯一动作/Outbox，另报丢失/重复和撤销一致性 |
| 原因填写率 | 窗内明确提交的唯一 event_id / 同期符合试验资格的成功点踩；另报菜单回执覆盖，主分母不只取打开菜单者 |
| 填写耗时 | 同一客户端单调时钟的挂载到提交主动耗时，以及点踩到提交总耗时；中位数/p90、未完成和缺失分报，后台/跨会话规则预定义 |
| 跳过/拒填/都不是/未响应 | 显式操作分别计，关闭不暗转拒填；未响应按冻结观察窗，断线/未知展示单列 |
| 更正与撤销 | 原因更正、动作撤销、推测撤销分别以曾提交原因/成功动作/有推测动作为分母 |
| 来源混淆 | 理解测试中误认系统推测为用户确认的比例，与事件非法转换/下游污染审计计数分别报告 |
| 处理价值 | 盲评量表判定可定位/路由/处理的反馈 / 全部合格成功点踩；补处理分钟数、误路由、实际处理比例，不以标签数量替代价值 |
