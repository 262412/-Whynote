## 3. 最近一轮安排：公开语料与个人云聊天试用

### 方案判断

两条线互补，公开数据不必等个人接入完成；个人试用也不必等所有数据集审查完。没有现成数据集能够提供本工具的真实菜单填写率、主动耗时和处理价值。本人随机聊天可发现问题，但应与固定测试任务分开，不把多个会话当多个参与者。

| 候选 | 内容及语言 | 反馈来源/许可 | 建议 |
| --- | --- | --- | --- |
| [WildFB](https://huggingface.co/datasets/THU-KEG/WildFB) | 对话历史、目标内容、`user_feedback`、满意度 label；中英；官方称约 18.6 万条 | 原始用户后续话语＋自动分类；卡标 MIT，上游 [WildChat](https://huggingface.co/datasets/allenai/WildChat-4.8M) 为 ODC-BY | 优先审查中文显式纠错/不满；label 不是用户确认原因；中文可用数待实际抽样 |
| [HelpSteer3-Feedback](https://huggingface.co/datasets/nvidia/HelpSteer3) | `context`、两份回答和分别对应的人工反馈；含中文问答 | 受聘评价员；CC-BY-4.0；[论文](https://arxiv.org/html/2503.04378v1)说明反馈文字统一英文 | 补充答案质量与分类覆盖；不是原提问者动机。固定 `feedback` 子集，避免误用默认 preference |
| [WildFeedback](https://huggingface.co/datasets/microsoft/WildFeedback) | 英文多轮会话与反馈信号、偏好对 | ODC-BY；自动 SAT/DSAT 注释，部分优选回答由模型生成 | 英文备选；优先原始语境及反馈关联，不以派生标签作 gold |

本轮固定数据仓库版本：WildFB `0791dbc3101c6be7e0316cba1d8caf10c28917ad`；HelpSteer3 `f6d145777bcbde96137596340fab89793acd1031`；WildFeedback `8b1a3e530b949d6aacfad6ba8912e209a05bc846`。本轮查阅公开资料与元数据，没有导入数据集正文。HelpSteer2 / UltraFeedback 保留为辅助候选；COIG-P / Arena 的既有准入未决项不因此解除。

## 5. 指标与实验准备

数值目标、样本量/时长、最小有意义改善、观察窗、排除条件与停止规则在实验前冻结；工程 24 小时窗不自动成为研究时长。自然操作与固定任务分报；本人多次聊天仍 N=1，不以会话数冒充独立用户数。

| 指标 | 最小可测口径 |
| --- | --- |
| 动作完整性 | 去重意图→受理→唯一动作/Outbox 对账；单列丢失、重复、撤销一致性 |
| 自然点踩率 | self_natural 合格回答上的点踩 / 全部合格回答；不掺入脚本强制点踩 |
| 原因填写率 | 观察窗内明确选因的唯一动作 / 全部合格成功点踩；主分母保留撤销项，另报展示覆盖 |
| 填写耗时 | 主动耗时与点踩至提交总耗时分开；中位数/p90、有效数和缺失；公开语料无操作时间记不适用 |
| 跳过/拒填/都不是/关闭/未响应 | 分别报告；unknown 类别不等于无原因；断线/未知展示单列 |
| 更正/撤销 | 原因更正、动作撤销、推测撤销分别统计；未启推断时推测撤销不适用 |
| 来源理解 | 问清本人选择、评价员判断、模型推测是谁提供；未展示模型建议时相关混淆率不适用，不填零 |
| 处理价值 | 预定量表下可定位/路由/采取行动的反馈比例、处理分钟数与实例；单人自评标局限，独立盲评另报 |
