# 本地反馈闭环测试宿主契约

状态：PRD FR-01、FR-10、FR-11、FR-13 与技术文档 TD-01/TD-04 的本地端到端验证切片。2026-09-26 核对飞书 PRD 修订 67、技术文档修订 8。此宿主仅使用虚构目标、临时测试身份和候选原因码；不是获批的客户端或生产身份系统。

## 本地请求与事件流程

`python -m whynote.demo` 只监听 `127.0.0.1`，并创建随机测试会话。浏览器访问 `/demo`，点击点踩后向已有动作 API 提交固定的虚构目标版本；动作和 Gate Outbox 先持久化。页面实际插入常规原因菜单并经过渲染帧后，以该会话向本地测试宿主的 `/demo/rendered-displays` 发送 `event_id`、新 `display_id`、`mode`、`ui_version` 和实际展示的原因码。宿主复核会话、当前目标权限和动作归属，再调用 `EventStore.record_display`。只在成功记录展示后启用原因提交。

用户选择原因产生 `reason_selected`，再次打开编辑菜单并更正产生 `reason_edited`；撤销点踩产生 `action_retracted`。选择与更正仍经过现有公共归因 API 的展示绑定、合法状态和幂等检查。展示事件只含原因码及展示元数据，不含问题、回答或测试会话令牌。

本地 `/demo/rendered-displays` 是测试用浏览器回执：同源页面持有临时会话令牌，只证明测试页面按流程发送了回执，**不能充当生产环境可信渲染证明**。正式宿主仍须提供真实身份、对象权限、客户端渲染回执及防重放机制；`whynote.api:app` 默认继续拒绝业务请求。候选原因标签和页面文案只用于测试，不代表 taxonomy 或用户体验已获产品签署。无生产上下文、供应商调用、auto-attach 或自由文本。

## 兼容、失败与回滚

本切片不改事件或 SQLite schema。测试宿主的会话无效、非本机请求、对象无权限、展示已过期或动作已撤销时拒绝回执；失败不追加展示事件。相同 `display_id` 与同一内容重试沿用已有展示，内容不一致时冲突。移除本地测试宿主不会改变已有动作/事件重放；生产代码无需启用它。
