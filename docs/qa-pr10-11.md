## 可以保留的局部通过项

- √ 新评分不传 snapshot 时接受且持久化为 null；创建或更新时传非空 snapshot 返回 422。普通所有者 GET 200，其他普通用户 GET 404；已加开关的管理员 GET 导出、列表、ID 列表和他人明细返回 401。Q-12/Q-13 仍使整体权限矩阵不通过。
- √ 越权单条聊天删除返回 False；实际批量、文件夹及账号删除方法可执行，所测关联评分得到清理。账号和聊天均删除。活动异步 SQLite 连接的 secure_delete=1、journal_mode=delete；这不证明备份或物理副本已擦除。
- √ 签名值的正常选择/更正、篡改拒绝、跨会话重放拒绝、断线和超时的既有测试通过。累计事件库含三条动作流，其中新浏览器流为动作 → 展示 → 选择 → 展示 → 更正，另有旧轮次与无会话接口流；全库不能误报为只有一个动作。库中未检出虚构问答哨兵，宿主原生 feedback 为 0。
- 已排除自动评审中的 NameError 疑点：固定版本的 ChatMessage 删除语句使用独立 select，未引用被改名的 `chat_id_subquery`；真实账号删除返回 True。该项不列为缺陷。
